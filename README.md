Fee oracle CLI — stub rate, job tag.

## Features

- Algorithm tag sha256
- Stub job + nonce scan
- No GPU/CUDA runtime required

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd fee-oracle-cli
cargo build --release
./target/release/fee-oracle-cli --help
```

## Tests

